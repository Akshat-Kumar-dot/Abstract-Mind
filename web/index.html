How it works

  1. 1

    Upload your file

    Drop in a manuscript as PDF, Word or LaTeX. The file is read in memory, never stored and never logged.

  2. 2

    We read the structure

    The header, abstract, declarations and references are found from the layout, so cited authors never appear as authors.

  3. 3

    Check, copy, done

    Every field is marked verified or worth a look. Edit anything; it’s encrypted before it’s saved.

What you get from every paper

  • Authors in orderFirst and last names, emails, ORCID iDs and the corresponding author.
  • AffiliationsDepartment, institution, city and country, linked to each author by markers.
  • Title, abstract, keywordsExactly as printed, ready to paste.
  • DeclarationsFunding and grant numbers, conflicts of interest, data availability, ethics.
  • Publication detailsDOI, publisher, journal, volume and dates for published papers.
  • CountsPages, words, figures, tables and references.

What an extraction looks like

Each paper gets its own page with an overview, the abstract, every author, declarations and counts. Rows marked with a dot are worth a second look.

        Privacy

        • Only you can read your libraryPapers are encrypted in this browser with a key made from your password before they’re saved. The server stores scrambled text it can’t open, and so does anyone with access to it.
        • Files aren’t keptAn upload is read in memory to find the details, then dropped. It’s never written to disk or logged.
        • Your password can’t be resetNobody else has the key. If you forget your password, your saved papers can’t be recovered.
